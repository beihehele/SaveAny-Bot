2026-10-13。产品范围为个人 Telegram 文件本地保存、单来源到单目标的监听/复制，以及可选的 admin 管理网页。审查基线为 `dev` 的 `c96459b`；本轮修复仍在工作区，未提交或发布。WSL 是验收环境，最终飞牛 NAS 部署尚未进行。

## 审查标准

优先保证正常操作可靠、错误反馈清楚、代码便于维护。仅修复已复现的问题和确定闲置的实现。保留权限检查、本地路径边界、原子保存、取消传播和既有 hooks；不为个人自用增加多用户租户隔离、配额体系、通用重试框架、模板沙箱或持久任务重放。此范围也写入项目 `AGENTS.md`，供后续维护遵循。

全项目 Go 声明与引用扫描覆盖基线的 306 个 Go 文件；结合入口、调用链、模块边界、现有回归和真实验收审阅业务行为。重点核对 Telegram 读取、任务接纳/终态、监听调度、本地保存、数据库列表缓存、网页表单、认证和发布运维。自动扫描不用于判断动态注册项是否应删除。

## 已确认的问题与本地修复

| 问题 | 证据与修改 |
| --- | --- |
| 消息元数据长期缓存返回旧 caption 和已删除的组成员 | 回归预置旧缓存，再让实际 RPC 模拟返回修改后的 caption、移除一个成员；旧代码两个入口均失败。删除 `tgmsg:` 对象缓存，单条/范围读取当前 Telegram 元数据。回归通过。聊天与 Topic 的数据库缓存不变。 |
| 媒体组目录规则丢弃单成员，并在单文件入口使用字面规则标记作为目录 | `NEW-FOR-ALBUM` 规则下，批量仅选择一个成员时没有入队。移除错误的成员数量跳过；单文件入口按所选成员的文件名建立目录。覆盖单成员、双成员、单文件入口的接纳数量及实际保存路径。 |
| 本地保存表单提交中可编辑，旧响应会清空新输入 | 提交期间锁定该表单控件，结束后恢复；成功反馈核对当前登录会话。浏览器延迟响应验证锁定、解锁、清空已提交链接及跳转任务列表。 |
| 保存请求响应未确认时缺少持续提示 | 网络错误/5xx 保留链接，显示先检查任务列表的提示和入口，不自动重复创建任务。模拟 503 验证保留输入、解锁及无自动重试。 |
| Webhook 调试日志包含完整地址 | 成功日志去掉目标 URL，常见 `url.Error` 只记录内部原因，避免输出地址中的口令/路径/查询参数。回归保留网络错误原因并核对敏感地址未输出。 |
| 子进程取消测试偶发误判 | 本地容器首次回归中 PID 文件已存在但尚未写完，测试无法取得两个进程。测试夹具改为写完后原子发布就绪文件；hooks 业务实现不变。首次失败日志保留，重新验证结果单独记录。 |

消息缓存删除会增加重复读取时的 Telegram 请求，但使读取与当前消息状态一致；没有另建一层缓存或复杂失效机制。已接纳的任务继续使用接纳时的选取结果，不自动跟随后续编辑重新规划。

清理了无调用的 `SendWebhook` 入口、没有消费者的 API token context 注入、闲置 `config.Docker` 变量及 Docker `-X` 注入、无引用的翻译键和过时 TODO；缓存拒绝日志不再输出完整对象。后台诊断增加现有扫描单页时限的只读展示。没有新增服务、依赖或数据库迁移。

## 整体评价

| 方面 | 结论 |
| --- | --- |
| 产品与 UI | 单来源/单目标、控件内搜索、显式列表刷新、默认不指定 Topic、radio 和字面关键词适合个人使用。提交状态和结果提示保持直接；不恢复多选、任务分组或复杂向导。 |
| 架构 | Bot、管理网页和可选 API 共用任务与本地存储能力；现有接口服务于这些入口，没有必要为单 Local 后端重写整条调用链。 |

| 本地文件与取消 | 保留受约束的根目录、临时文件发布、重复文件策略和取消后清理。它们直接保护文件和任务结果。 |
| 认证与隐私 | 保留固定 admin、配置口令/哈希、会话与 CSRF、配置/会话下载保护。可选 API 继续可关闭；没有追加企业权限模型。 |
| 兼容与冗余 | 不保留项目历史版本兼容：移除旧配置特判、废弃 API 字段和旧监听索引修复。plain/typed Telegram ID 是当前协议需求；终态事件必须有明确 worker 决定。生成 enum 的标准方法与审查记录有当前生成/审计用途。 |
| 配置与文档 | 活跃文档只描述当前 Telegram/Local 能力；已删除旧版本迁移说明及引用，发布说明整理为当前功能和行为边界。43 个本地链接按文件和 Hugo 目录路由检查无缺失；未检查外部网站或执行 Hugo 渲染。 |
| 运维与发布 | 继续固定候选摘要、单实例切换、备份和回退。WSL 验收结果不代替 NAS 的目录权限、重启与恢复验收。 |
