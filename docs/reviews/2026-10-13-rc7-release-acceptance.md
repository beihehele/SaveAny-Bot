2026-10-13：本轮 Web 管理改造已提交、推送、打包并在 WSL 验收实例验证。当前候选为 `v2.0.0-rc.7`，代码提交 `1beda1454bb6c32872e547617253ede5e26d546d`。WSL 仍是验收环境；飞牛 NAS 迁移未执行。本轮通过不代替下文列出的异常场景专项。

## 发布过程中的发现与修复

- `486df2a` 提交单来源/单目标管理、聊天与 Topic 持久缓存、radio、关键词过滤及任务反馈改造，并清理类型化分页游标、闲置翻译键和重复样式。
- rc.6 实际镜像的浏览器验收发现 `management.js` 未加入服务端静态资源白名单，返回 404，页面停在加载画面。原嵌入文件检查和模拟网页没有覆盖这个 HTTP 入口。原生 Bot 命令正常不能证明网页可用，rc.6 不作为通过版本。
- `1beda14` 仅补齐该脚本白名单并增加从实际首页提取资源地址、验证 HTTP 状态/内容/MIME/nosniff 的回归。白名单和安全响应头继续保留。重新发布 rc.7，未移动或覆盖 rc.6 标签。
- 私有辅助验收工具原来只查最新 100 条测试源历史，旧照片素材被上一轮测试文本挤出范围，发送前即中止。工具改为最多四页有界读取后重新验收；修改留在忽略的测试目录，未纳入业务代码。失败轮临时监听已清理。
- 追加浏览器验证时一次只读 Bot API 身份查询超时，重新查询成功。未对未确认的发送请求自动重试，也未改代理、共享 Telegram 会话或媒体组业务逻辑。

## 发布判断与剩余范围

推荐保留 rc.7 作为完成本轮功能验收的候选版本，rc.6 由其替代。没有发现本轮新增功能的剩余发布阻断问题；不据此提升为稳定版本或迁移 NAS。

- 真实撤销管理权限/变更论坛能力后的操作，仍只有模拟校验和缓存失效回归，本轮未对真实管理聊天制造权限变更。
- 连续真实扫描超时后恢复、无部分发送的完整复核、交错到达时序和有界媒体组查询完整性仍是既有验收边界。本轮成功组和取消测试不证明所有时序场景。
- 辅助客户端命令接收偶发异常的根因未完全确定；原生命令入口以用户常用客户端对照，自动媒体准备采用独立无 updates 的临时会话。测试工具分页问题已明确修复，不能据此宣称其他辅助客户端问题均已解决。
- 飞牛 NAS 迁移需准备 Docker 管理/连接方式和配置、数据、下载、备份目录，再做单实例切换、恢复演练及目标机器验收。目前 WSL 不承担最终生产部署结论。

后续代码完善可依据实际使用反馈评估监听编辑和目录/规则管理，继续保留 1→1 模型；本轮不追加多来源或任务分组设计。
