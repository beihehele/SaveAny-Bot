# Contributing

This branch focuses on Telegram and local saves. Follow AGENTS.md and use isolated configuration, databases, sessions and download roots.

Preserve albums, topics, filters, naming, directory rules and task hooks. Check all callers before pruning shared helpers. Keep English/Chinese translations and generated i18n keys consistent.

Run tests, vet, race regressions, the alternate SQLite build and Docker deployment checks. Record real Telegram acceptance separately from automated tests.
