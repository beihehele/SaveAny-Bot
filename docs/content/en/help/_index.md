# Troubleshooting

For save failures, check source access, local directory permissions, free disk space and task logs. Watching and history copying need an authenticated Userbot and destination chat/topic write access.

For album issues, check source messages, GroupedID, filters and destination topics using the [watch checklist](../usage/watch). Keep databases and sessions while diagnosing save failures.
