# 复制历史消息

{{< hint warning >}}
该功能需开启 UserBot 集成.
{{< /hint >}}

将源频道/群的历史消息按条件筛选后，整条转发到目标聊天（可指定论坛话题）。仅转发、不下载、不落本地存储。

## 用法

```
/copy <source_id> <target_id[:topicId]> [filter] [count]
```

| 参数 | 说明 |
|---|---|
| `source_id` | 源聊天 ID 或用户名（必填） |
| `target_id[:topicId]` | 目标聊天（必填）；不支持 `0`；`:topicId` 为论坛话题 ID（见 `/lstopic`） |
| `filter` | 可选，仅支持 `msgre:<正则>`；省略则几乎每条消息都命中 |
| `count` | 可选，命中条数，默认 500，最大 5000；从新到旧凑够为止 |

示例:

```
/copy -1002229835658 -1003333444555
/copy -1002229835658 -1003333444555:12345 msgre:.*hello.*
/copy -1002229835658 -1003333444555 msgre:.*hello.* 100
/copy -1002229835658 -1003333444555 50
```

## 行为说明

- 进度分两阶段：扫描（`matched/count`）→ 转发（`done/total`），可点取消按钮或用 `/cancel` 停止
- 同一用户同时只能有一个进行中的 `/copy` 任务
- 相册按组整组转发；拆段无 caption 续组在消息 ID 紧挨时可顺带（不占 count，上限 5）
- 转发由 **UserBot 个人账号** 执行，使用无来源复制（`DropAuthor`）
- **不会**弹出存储选择键盘

## 与 /watch 的区别

| | `/watch` | `/copy` |
|---|---|---|
| 时机 | 实时监听新消息 | 回溯历史消息 |
| 目标 `0` | 可保存到默认存储 | 不支持 |
| 输出 | 本地存储或转发 | 仅转发 |
